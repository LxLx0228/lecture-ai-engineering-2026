基礎では実行時に `app.retrieval.RAG_TOP_K` だけを5から3に変更した。どちらも `search_materials` を「LoRA QLoRA 固定 学習」で1回呼び、p.51–52は上位3件に残った。この質問では入力が950トークン減った。

実装では同じ資料IDのPDFページ番号を基準に前後1ページの本文を足し、ページIDで重複を除いた。元の検索結果を先に返す。LoRAの例では5ページが11ページに増えたが、追加したページから新しい根拠は使われなかった。一方、検索語を「Claude コンパクション」に絞ると、通常検索の5件に含まれなかった第3回 p.40が、p.39の隣として取得できた。Claudeの事例を入口にOpenClawの日々のメモの説明も探す場合に役立つ。

### 発展　Graphで複数の起点から届くページを優先

質問は「第3回の例では、コンパクションとセッションをまたぐメモリはどう違いますか。日々のメモはすべて長期メモリに入りますか」。第3回 PDF p.13に外部保存と読み戻しの模式図、p.39にClaudeのセッション内の要約と外部メモリの違い、p.40にOpenClawが日々のメモを選別する例があることを先に確認した。

`app/retrieval.py` では、既存のページ単位のベクトル索引と `graph.json` を使う。上位3ページを起点に、前後ページと共通用語の辺をそれぞれ最大2 hopだけたどる。各候補へ届いた起点を数え、複数から届くページを優先する。同数の場合は経路が短い順、経由する用語の接続先が少ない順、起点の検索順位順に並べる。モデルへ渡す本文は起点を含めて最大5ページとした。複数の候補が同じ説明につながる場合に、その説明を優先しつつ、本文の量を抑えるため。

`app/tools.py` で検索結果を返すツールを定義し、`app/agent.py` で `--adjacent` と `--focused-graph` を選べるようにした。`--trace` に取得ページのIDを表示し、取得したページと最終回答で使ったページを照合した。

| 方式 | 回答の要点と引用 | 時間（秒） | 入力／出力トークン | モデル応答回数 | 生成API推定費用（USD） |
|---|---|---:|---:|---:|---:|
| 通常のベクトル検索 | セッション内の要約と外に保存して読み戻す仕組みを説明。日々のメモは基準を超えたものだけ残す。第3回 PDF p.39、40、65 | 3.60 | 2,500／433 | 2 | 0.001832 |
| 元のGraph（最大10ページ） | 同じ3点を説明。第3回 PDF p.38–40、65 | 4.24 | 5,301／444 | 2 | 0.002153 |
| 改良Graph（最大5ページ） | 同じ3点を説明。第3回 PDF p.39、40、65 | 13.60 | 2,483／475 | 2 | 0.001932 |

通常検索と改良Graphは「コンパクション セッション メモリ 長期メモリ 日々のメモ」でそれぞれ検索ツールを1回呼んだ。改良Graphは第3回 p.39、65、38を起点に、p.40と37を追加した。追加したp.40が「全部は残さない」という回答の根拠に使われた。元のGraphは「コンパクション セッション 長期メモリ 第3回」で1回検索した。検索語の違いを除くため同じ検索語に固定して取得だけも比べたところ、元のGraphと改良Graphの両方でp.40を取得し、改良版は5ページに収まった。

今回の複数ページの質問では、元のGraphより入力を約53%減らしても主要な根拠が残った。基本RAGとの差は17入力トークンで、回答も同程度だった。改良版のほうが応答に時間がかかり、推定費用も基本RAGを少し上回った。短い「Claude コンパクション」で各方式に同じベクトル検索結果を渡すと、元のGraphと前後ページの方式はp.40を拾ったが、改良Graphではp.40が5件の枠から落ちた。特定の1ページだけが持つ根拠は、複数の起点からのつながりを優先すると落ちることがある。

「今回作ったRAGの実測平均応答時間と正答率を教えてください」という質問では、両方式ともページを取得したが、必要な数値を資料からは確認できないと答えた。関連ページが返っても、質問に答えるための数値が載っているとは限らない。

普段は基本RAGを使い、答えに必要なページが検索結果から抜けたときにGraphや前後ページだけを試したい。次に試すなら、長い質問を論点ごとに検索し、論点ごとに最低1ページを残した場合に、p.40のような取りこぼしが減るかを見たい。

### 再現

```bash
Q='第3回の例では、コンパクションとセッションをまたぐメモリはどう違いますか。日々のメモはすべて長期メモリに入りますか'
uv run python -m app.agent --trace "$Q"
uv run python -m app.agent --adjacent --trace "$Q"
uv run python -m app.agent --graph --trace "$Q"
uv run python -m app.agent --focused-graph --trace "$Q"
```

ローカルのPython 3.12.3では `sqlite3` の拡張読み込みを利用できなかったため、ベクトル検索とGraphは拡張を読み込めるPython 3.12.7の環境で計測した。
