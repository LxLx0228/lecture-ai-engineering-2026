# 第1回 自動記録ツール

## 起動

`uv run python -m app.study_cli`

ローカル用の `質問を始める.command` からも同じメニューが開きます。
前の版が起動中なら `/quit` で終了してから開き直します。
キーは起動時に非表示で入力し、メモリ上だけで保持します。

- 1: 基礎・発展の比較12回（2モデル×2問×3回）と、実装の会話確認2回を実行する。
- 2: 自由に質問。前の回答を次の質問に渡す。`/new` は履歴を消すが保存記録は残す。
- 3: 気づき、回答の正しさ、難しかったことを本人が入力する。追加API呼び出しなし。
- 4: 保存先と呼び出し回数を表示する。追加API呼び出しなし。
- 5: 直近の比較実験の続きを手動で実行する。成功済みのモデル・質問・回数の組は飛ばす。会話確認も保存済みなら飛ばす。
- 0: 保存して終了。

## 生成物と証拠

- `lectures/01/answer.md`: 実行のたびに自動集計区間を更新する。区間外の手書きは保持する。
- マーカーを削除した場合は原本を上書きせず `answer.generated.md` を作る。
- `.logs/lec01/events.jsonl`: 質問、表示回答、モデル、開始日時、応答秒、入力・出力・思考・合計トークン、履歴数、終了理由、エラーを保存。Git対象外。
- ローカル起動では `outputs/提出用/answer.md` にも同じ内容をコピーする。
- 比較12回が途中なら未完了と表示。失敗、本文なし、出力上限は成功と混同しない。
- 文字列比較と平均値の集計はPythonだけで行う。意味の正しさや本人の気づきを自動で作らない。
- 以前の起動ツールで表示しただけの回答は、この版では復元できない。

## 無料枠と上限

利用者は「無料枠のみ・エラー時自動再試行なし」を選択済み。
2026-10-26、本人のAI Studioでプロジェクトが無料枠であることと、以下を確認した。

| モデル | RPM | 入力TPM | RPD |
|---|---:|---:|---:|
| gemini-3.5-flash-lite | 15 | 250000 | 500 |
| gemini-3.1-flash-lite | 15 | 250000 | 500 |
| gemini-3.8-flash | 5 | 250000 | 20 |

現在の比較は gemini-3.5-flash-lite と gemini-3.1-flash-lite の2モデル。
以前の比較相手gemini-3.8-flashは503と504で失敗したため、無料枠を再確認した3.1 Flash Liteに設定を変更した。
既存の3.5 Flash Liteの6回答と旧モデルのエラーを保持し、5で残り6回から進められる。変更後も実行中の自動モデル切替はしない。
1起動30呼び出し、比較は1回の実行で最大12呼び出し、最初のまとめ実験は比較12＋会話2の計14呼び出し。
最低15秒の開始間隔。1回答2048出力トークン、質問2000文字、会話入力12000文字、保存回答10000文字。
ログは1件2万文字・合計20MBが上限。上限に近い場合は呼び出し前に止める。自動削除はしない。
SDKの試行回数を1にし、429・503などのAPIエラーがあればその起動中の追加呼び出しを停止する。

503はサービス利用不可（混雑など）、429はレート制限として区別する。
504はタイムアウトとして区別する。最新の実測では3.8 Flashが約59秒後に504を返した。401の認証拒否と混同しない。
エラーで止まったら0で終了して開き直し、後で5を選ぶ。5を本人が選ぶまで再試行しない。
再開では成功済みを再実行せず、失敗した枠と未実行の枠だけ実行する。失敗記録は削除しない。
手動再開を重ねた累計には失敗したAPI呼び出しも含まれるため、比較の成功12回より総呼び出し数が多くなる場合がある。

無料枠の状態はAPIレスポンスだけでは保証できない。課金設定済みプロジェクトや別のプロジェクトのキーは使わない。
確認日が変わった場合は、起動時に当日のAI Studioを確認してから進む。
同じプロジェクトの他の利用も枠を消費するため、15秒間隔でも429を完全には防げない。

公式資料:
- https://ai.google.dev/gemini-api/docs/rate-limits
- https://ai.google.dev/gemini-api/docs/billing
- https://googleapis.github.io/python-genai/
