# ローカル環境の既知事項

- MCPのテストは内部で `uv` を起動する。PATHにuvがないと2件失敗する。現在のローカル環境では `work/runtime/bin` をPATHに追加してテストする。起動ファイル自体は仮想環境のPythonを直接使う。
- 以前の質問用メニューには自動保存がない。表示済みの回答は新版へ自動移行できない。旧メニューを `/quit` で終了し、起動ファイルを開き直す。
- この環境ではターミナルのGUI自動操作が制限される。本人が起動ファイルを開く。キーをコマンド引数・チャット・ソースへ貼らない。
